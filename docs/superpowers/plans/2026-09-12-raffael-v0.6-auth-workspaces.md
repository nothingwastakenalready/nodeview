# Raffael v0.6 — auth and workspace implementation plan

1. Add the SQLAlchemy auth model boundary and an Alembic migration.
2. Add password/session services with explicit configuration and no secrets in
   logs or responses.
3. Add API dependencies for current user and workspace membership.
4. Add registration, login, session and logout endpoints.
5. Add CSRF protection for cookie-authenticated mutating requests.
6. Write unit tests for normalization, hashing and token lifecycle.
7. Write API tests for auth lifecycle and cross-workspace denial.
8. Run the full Python suite, fresh migration check, frontend suite/build and
   diff/security review.
9. Update project context, roadmap and README with the real limitations.

The existing dashboard redesign remains a separate follow-up slice and is not
part of this backend acceptance boundary.
